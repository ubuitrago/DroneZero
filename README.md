# Drone Control Pipeline

This project implements a pipeline for controlling a drone using zero-shot learning and flight planning. The pipeline processes text, image, and sensor data to generate and execute flight plans.

## Modules

### 1. `zsl_agent.py`
- **Purpose:** Implements a zero-shot learning agent for analyzing human gestures and environmental data.
- **Key Features:**
  - Analyzes text descriptions, images, and sensor data.
  - Identifies patterns and relationships in the data.
  - Provides insights for flight planning.
- **Usage:** Used to interpret human gestures and generate contextualized insights.

### 2. `flight_plan_agent.py`
- **Purpose:** Generates flight plans based on insights from the ZSLAgent.
- **Key Features:**
  - Takes insights from the ZSLAgent as input.
  - Generates a sequence of drone control commands.
  - Outputs a structured flight plan.
- **Usage:** Used to convert insights into actionable flight plans.

### 3. `drone_control.py`
- **Purpose:** Provides methods for controlling the drone.
- **Key Features:**
  - Methods for takeoff, landing, and movement.
  - Functions for getting and setting drone position and orientation.
  - Integration with the AirSim simulator.
- **Usage:** Used to execute the flight plans generated by the FlightPlanAgent.

### 4. `experiment.py`
- **Purpose:** Manages the execution of experiments and data recording.
- **Key Features:**
  - Records telemetry data and camera images.
  - Executes flight plans using the DroneController.
  - Saves experiment data to files.
- **Usage:** Used to run experiments and record data for analysis.

### 5. `run_pipeline.py`
- **Purpose:** Entrypoint for the drone control pipeline.
- **Key Features:**
  - Processes command-line arguments for text, image, and sensor data.
  - Initializes and runs the ZSLAgent and FlightPlanAgent.
  - Outputs the generated flight plan.
- **Usage:** Run this script to execute the pipeline with the desired inputs.

## Usage

To run the pipeline, use the following command:

```sh
python run_pipeline.py --text "Fly in a circle" --image "path/to/image.jpg" --sensor "1.0,2.0,3.0"
```

## Logging

Logs are written to the current directory. The log level is set to `INFO`, and new logs are appended to the file.

## Dependencies

- `langroid`
- `PIL` (Python Imaging Library)
- `argparse`
- `json`
- `logging`
- `airsim` (for drone control)
